## 4. Tensor, geometry, and public API contracts

All production floating tensors are FP32; CPU FP64 is a numerical-test mode. Reject AMP/FP16/BF16 in v1 production configs, including accidental autocast. Device and bounded chunk sizes are operational choices. Batch rows must have identical geometry to share one FeatureGridGeometry, otherwise process separately. No batch normalization or cross-subject reduction is introduced downstream.

| Field | Shape / invariant |
|---|---|

| geometry | Existing VolumeGeometry; `[w,h,d,1]→RAS XYZ mm`; explicit spacing and full affine |
| shallow / layer1 / deep | Existing MedicalNetFeatures from one traversal; 64 / 64 / 512 channels, actual observed spatial grids |

W1 `types.py` defines frozen metadata dataclasses with shape/type/role validation; immutability requires owned tensors and mutation/version guards, not `frozen=True` alone:

- `GainLabel`: action/context/state IDs, raw signed g, benefit/harm, M, exact/fixed-Q/screening role, Q, iid law/probabilities/seed, variance/SE (or null when unavailable), footprint/count/provenance fields.
- `GainCalibration`: a,b, nonnegative allowance, quantile definition, fit/allowance role hashes, counts, model/policy/scale/dependency hashes, version and capability status.

## 6. W2 signed teacher, footprint, and exact sparse evaluation

Fix `rho(e)=sqrt(e²+eps²)` with `eps=1e-3` in v1 (subtracting eps is an equivalent constant only when recorded explicitly). Let observation-derived binary mask m be fixed per subject, `M=sum(m)>0`, and `R(Z)=sum(m*rho(D(Z)-Y))/M`. For an already generated actual delta, **g=R(before)−R(after)**. Save g in raw normalized-intensity loss units, benefit/harm separately with `g=benefit−harm`; no target or error normalization enters proposals/geometry. Teacher uses only this pointwise objective. SSIM and gradient loss stay outside the footprint cancellation theorem.

Reference engine: immutable current state → actual existing CompactTriPlaneWriteback with the supplied delta → existing decoder before/after at all output voxel centres → masked difference/M. It bypasses U recomputation and does not use sparse helper outputs to define reference support. Keep this intentionally simple full-write exact baseline permanently callable for tests and same-work benchmarks.

Sparse geometry and sampler:

1. Reproduce actual discrete writer node weights, including local-window clipping and full affine distance with omitted feature coordinate fixed to the point. Weight `max(1−distance/4,0)²`; use **strict positive weight** for support, no epsilon pruning.
2. At each possible retained source-grid pair compute the actual four bilinear neighbors with zero padding and align_corners=False. A plane pair belongs if its weighted discrete write kernel is positive. Extrude along the omitted output-grid axis; footprint is the **union**, not sphere/intersection/three centre fibres. Rotation/shear extrusions follow the image lattice, not global anatomical axes.
3. Enumerate unique voxels in bounded chunks for exact mode; deduplicate overlaps before loss summation. No `[N,D,H,W]` allocation. Store compact pair lists and membership tests. Empty geometric support is an illegal correction; an all-masked-out effect is a valid zero-gain label. Empty subject mask is a validation error.
4. MAIN fixed-Q law: let n_phi be each unmasked geometric extrusion cardinality, S=sum(n_phi), c(v) its multiplicity (1..3). Choose plane with probability n_phi/S, uniformly select retained pair and omitted index. Then **p(v)=c(v)/S>0** on the full union. Mask appears only in the integrand; no mask rejection with an unknown denominator.
5. For Q independent draws with replacement, `g_hat=mean(m(v)*[rho(before−Y)−rho(after−Y)]/(M*p(v)))`. Store Q, full law/version, seed, multiplicities/probabilities or reproducible compressed sample record, per-draw weighted variance and SE; Q≥2 for an estimated SE. Duplicate samples remain draws even if decode caching deduplicates them. `exact_footprint` has MC uncertainty zero; numerical tolerance is separate. Uniform-union sampling is an alternative only with its exact cardinality and probability recorded.

Sparse engine computes `q_before=query(Z,v)`, `dq=cat(k_xy(v)*delta_xy,k_xz(v)*delta_xz,k_yz(v)*delta_yz)` and evaluates the **same nonlinear `decoder.mlp(q_before+dq)`**. It must not linearize D, construct hypothetical full planes, or substitute continuous-sphere weights for the discrete stencil. Exact algebra becomes numerically equivalent implementation due to floating accumulation order. Chunk over candidates and query rows; do not allocate N×Q×96 without respecting configured bounds.

Caches: target context owns detached validated Y/mask, M, tensor mutation/version checks and subject/normalization/geometry/provenance identity once per subject; direct integer DHW gathers address voxel centres. Geometry caches key point/source/feature affine/kernel/writer version and dtype. Before-query features key state/context/query IDs; predictions additionally key D hash. Any mutation, new state version, producer change, device/dtype change or mismatch invalidates relevant cache. Public buffers cannot be mutated undetected. Cache target validation once, not N times; target context never reaches deployment.

Classification ledger in code metadata and benchmark: **EXACT ALGEBRA** (query linearity/cancellation); **NUMERICALLY EQUIVALENT** (batched U/D, query-delta, cache reuse under validated keys); **APPROXIMATE** (finite iid estimates, adaptive screen, less candidate/state work, any future lower precision). No Taylor/Jacobian optimization in v1. Adaptive screens may be an explicit later diagnostic only; save screen observations separately, then independent exact/fixed-Q winner labels. Never call a noisy screening winner an all-N exact oracle.

Expose differentiable query-delta primitive for correction-gradient tests, but `measure_actions` is always no-grad. W3 differentiable S1 loss does not call the detached teacher. Instrument cache validation time, before/after output counts, unique query rows, actual MLP invocations, kernel/window work and clone bytes.

## 8. W4 immutable action, policy, calibration, and checkpoints

Flatten `[B,N,270]→[B*N,270]`, call the existing UpdateNet in bounded chunks, reshape actual delta and preserve row/point ordering. No changes to legacy UpdateNet are required. The scorer receives the stored proposal, and execution gathers **exactly that delta**; never call U again for the selected action. Per-subject state version increments only on executed writes. Stale context/state/point/U/writer/geometry versions and mutated proposal tensors are errors, not silently recomputed actions.

Effective policy fields: schema=`pfgr-lite-policy-v1`, mode, K∈{0,1,2,4}, revisit=`allow` MAIN, deterministic lowest-point-ID ties, raw gain units, calibration hash, quality margin, candidate-independent next-compute cost (default0), legal rules, action/writer/config versions. Legacy travel/overlap/lambda_step/ST flags are **unknown fields** in PFGR and rejected.

For legal action i compute `raw_i=scale*V(d_i)`, `mu_i=a*raw_i+b`, `value_i=mu_i−allowance−quality_margin−compute_cost`. Same value ranks and witnesses continuation. STOP iff no legal action or best value≤0; exact ties at zero STOP. Nonfinite inputs, outputs, calibrations, deltas or states fail with typed numerical error; they do not masquerade as low gain. Exact zero deltas are no-op diagnostics, excluded from legal adaptive correction even if affine intercept is positive. No retained writer support is illegal. No target-derived legality or no-revisit default.

K0 returns D(Z0) with **zero proposal and V assessments**, reason `budget`; it still records frontend/static/decode cost. For K>0, a genuine low-gain exit pays for its terminal assessment. After an executed fourth write stop for `budget` without a fifth assessment. Distinguish `budget`, `low_gain`, `no_legal_action`; do not relabel budget as model confidence. Revisited point IDs receive fresh proposals after every write. Diagnostic forced greedy executes its best legal nonzero proposal even if predicted gain is negative, up to budget, and is explicitly selected by policy mode; train/eval mode does not force a first action. All-inactive batch rows must not be scored again.

## 9. W5 scenarios, metrics, and scientific decisions

Every comparison shares subject/preprocessing/mask/target scaling/Z0/U/D/points/spectral snapshot and starts from the same Z0. Save paired D(Z0) and final metrics even for K0. Primary deployment scenarios:

`static`, `noop`, `random` K1/2/4, `fixed_learned` sequential K1/2/4, `adaptive` K≤4, and `parallel_topk` K1/2/4. Random uses a saved seed/with-replacement stream; report repeat variability. Parallel generates/values every candidate once at Z0, freezes its actual proposals, selects topK with deterministic IDs, and sums writes as one explicitly diagnostic compound action; no proposal refresh or hidden overlap normalization. Default forced parallel comparator isolates ranking at K; a positive-only variant must have a distinct name/count. Record joint gain and `interaction=joint_gain−sum(individual_gains_at_Z0)`. Additive write commutation does not imply additive loss improvement.

Privileged scenarios live behind `oracle-evaluate`, not deployment `evaluate`: sampled subset Oracle1 with STOP0, greedy OracleK, and small-cohort all-candidate **exact** Oracle1. At every oracle state generate candidates/deltas before teacher access. A screened all-N/confirmed-subset result is labeled precisely; independent confirm samples measure winners and do not turn screening into exhaustive exact evidence. Greedy OracleK is not a global K-step bound and may be beaten by another sequence. No-op has exactly zero measured gain. Oracle trace/context types cannot enter deployment APIs/checkpoints/banks labeled target-free.

Additional experiments: local-sphere versus full-footprint labels for the **same actions**; V126/V222/V270/V366 on exactly the same bank; reference full-write versus sparse same-work benchmark; sampled-Q fidelity against exact references; sequential versus parallel at equal writes and separately matched measured end-to-end compute.

Metrics/reductions contract:

- Per subject: D(Z0), final and signed deltas for MAE, PSNR, SSIM, masked Charbonnier. Positive improvement convention is before−after for errors and after−before for PSNR/SSIM. Persist formula, data range, mask, reduction, normalization-space label. Use current masked_robust_01 range1 only when that is the declared pipeline; z-score needs explicit metric range. Never infer range from target maxima at evaluation. Tiny volumes lacking a valid SSIM window report unavailable with reason/count, not fake SSIM0/1.
- Paired action rows: predicted raw/scaled/calibrated/value, measured true g/b/h, mode/Q/SE, M and footprint sizes, identities/state/proposal hashes, selected/random/oracle role, local diagnostic loss and complete-footprint loss, score/label population counts. Preserve harmful, neutral, invalid and rejected outcomes. Numerical-neutral uses declared measurement tolerance/uncertainty; practical-useful uses the distinct quality margin.
- Headroom: `correction_headroom=G_oracle−0`, `selection_headroom=G_oracle−G_random`, `learned_minus_random`, `learned_minus_Z0`. Oracle-gap recovery only when oracle−random is reliably positive above the predeclared practical margin; otherwise null with INCONCLUSIVE reason, never divide by epsilon. Retain negative/greater-than-one recoveries if meaningful, do not clip them.
- Stopping: false stop means low_gain despite a measured useful alternative in an explicit candidate scope; budget exit excluded. Harmful selection means measured selected g<0 beyond measurement tolerance, independent of alternatives. False continuation means continuing when **best true legal action in the audited scope** does not clear the quality/cost threshold; unknown if only selected action measured. Harmful selected action with another useful alternative is selection failure, not proof no continuation was useful. Report subset-detected false stops as lower-bound detections, never all-N absence-of-headroom evidence.
- Routes: numeric `k_0..k_4` bins, subject counts, Kmean/conditional-active/repeat count, no-op count, stop counts, selected-action identity checks, exact cumulative measured gain and telescoping residual `sum(g_t)−(R(Z0)−R(ZK))`. Fixed-Q cumulative estimates include MC uncertainty/covariance assumptions and are not required to exactly telescope.
- Training: per-module nonzero gradient norm/changed count, before/after frozen parameter and BN hashes, spectral-producer stage provenance, U saturation/write norms, V fit teacher/U/D call counters all zero, scale-floor flag, constant-training-mean MSE comparator and within-state ranking/sign/top1 subset regret with tie/undefined cases explicit.
- Work: MedicalNet traversals, candidate proposals, V evaluations, pre-mask eligible evaluations, executed writes, behavior states reached, states labeled, candidate labels, exact sphere-valid voxels, padded cube slots, footprint unique voxels, sampled draws, unique decoded queries, before/after decoder outputs, actual decoder/MLP calls, dense decodes, target validations/mask casts, cache hits/misses/build/validation time, full-plane clone bytes and bytes copied. Allocated and reserved peak CUDA memory separate; CPU values unavailable rather than fake0 GPU usage. Record actual device count/ranks/GPU names, never infer distributed execution from installed GPUs.
- Latency includes observation load/normalization when claimed end-to-end, frontend, Z0, U, V, write, initial and terminal assessment, final decode and synchronization; teacher timing separately, including cache setup and I/O. Warm/cold cache benchmark both, same saved actions/query lists/dtypes/chunks/repeats. Labels/sec speedup with fewer Q/states is **reduced work**, not same-work optimization.

Aggregator state uses explicit sum/count/max for each population; per-subject metric means are accumulated once per subject, max uses MAX, histograms numeric. Preserve bins and reason counters through JSONL/CSV and W&B, not a scalar-only filter that drops nested dicts. Test batch partition/permutation invariance and final short batches. Subject-paired confidence intervals use predeclared bootstrap seed/repeats, never treat thousands of candidate labels as independent subjects.

Scientific decision table (software success is independent):

| Evidence | Decision / next action |
|---|---|
| Oracle−Z0 reliably nonpositive or practically negligible with adequate precision/power | Correction claim FAIL for this trained U/base and audited candidate scope; stop router optimization and review U/base/measurement. Does not prove every possible correction impossible. |
| Oracle≈random and both reliably improve Z0 | Correction supported; selection headroom unestablished; retain simple random/fixed/parallel comparator. Learned-routing claim fails if an equivalence study supports negligible benefit; otherwise INCONCLUSIVE. |
| Oracle>random but learned≈random | Selection headroom exists; diagnose bank coverage/descriptor/V fit/calibration, not travel thresholds. |
| Learned>random and Z0, with measured useful decisions | Routing contribution supported at the declared cohort/compute/precision; test sequential and adaptive benefits separately. |
| Wide intervals, too few subjects/positive actions, noisy winners or incomplete all-N scope | **INCONCLUSIVE**, not FAIL and not PASS. Increase precision/appropriate bounded cohort only after review. |

Predeclare research margins and paired interval method in experiment manifest before target evaluation. PASS for positive incremental contribution requires lower paired interval above that margin; FAIL for a practically absent effect requires sufficient precision/equivalence evidence; otherwise INCONCLUSIVE. No hardcoded dB improvement, minimum K activity, oracle-random≈0 shortcut, or imported paper metric is a success gate.
